# ramlang

**Ram** is a C/C++-like systems programming language written in **Zig**, focused on predictable performance, explicit memory management, and low-level control.

### Features

* No garbage collector
* No inline assembly
* Explicit memory management
* Native compilation
* C/C++-inspired syntax
* Minimal runtime
* Systems-level programming

### Status

Early development.
